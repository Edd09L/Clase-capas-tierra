📋 Guía de Verificación y Uso Rápido (Para Docentes y Evaluadores)
  • Navegación Táctil/Teclado: Presione la tecla Tab para desplazarse secuencialmente por cada capa. Utilice las flechas del teclado o Enter para activar.
  • Lector de Voz Automático (Web Speech API): Al seleccionar una capa o presionar "Escuchar Descripción", el sistema leerá los datos adaptados y la equivalencia táctil.
  • Ajuste de Macrotipo y Contraste: Use el selector de temas para alternar a "Amarillo sobre Negro" (ideal para baja visión severa) y los botones A+ / A- para adaptar la escala gráfica y de texto.
